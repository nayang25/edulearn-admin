# EduLearn admin full-stack edition

Setup: START_HERE.md. API contract: API.md.

React/Vite website with Node.js/Express backend, Firebase Authentication and Firestore. The backend verifies ID tokens and membership, validates data, creates passcodes, imports rosters and records audit entries. Student/guardian editing and deletion are included.

Development uses two terminals: npm run dev:server and npm run dev. Server credentials are deliberately excluded from this archive.

The teacher/student apps are not connected. Deployment and live Firebase verification remain later steps.
